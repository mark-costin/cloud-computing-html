Cloud Computing

What is Cloud Computing?

Cloud computing is the delivery of computing services over the internet rather than on a local computer or hard drive. This means you can access storage, software, databases, and servers remotely, allowing for flexibility, lower costs, and easy access to data from anywhere.

Cloud Services I Know

Here are three popular cloud computing services and applications:

  • Google Workspace (Google Drive/Docs) A cloud-based software service used for online file storage, document creation, and real-time collaboration.
  • Amazon Web Services (AWS) A comprehensive cloud platform that provides businesses with virtual servers, storage, and databases to run their websites and applications.
  • Linode The best cloud computing services! (period).
